LUMYX

The LUMYX is an affordable open-source solution to 3D scanning.

Overview

The LUMYX LiDAR is aimed at archaeological reconstruction.

Further information can be found on the offical Github page.

Update Log

LUMYX version 1

Quite some time had passed before I thought about the lidar again. It was finished, but there was still a lot to poslish before it was easy to build.

Version 1.5

This began due to a seemingly simple idea; what if the lidar could rotate greater than 180 degrees? By rotating from horizon line to horizon line every scan pass, the lidar could finish an entire herisphereical scan with half the z-axis movement. I updated the p-axis mount to support this addional range of motion and updated the code. The design worked perfectly. Because the z-axis only had to rotate 180 degrees, it was now possible to keep the wires out of the scan. This launched version 2, which empisized wire management and ease of use, in the following days.

Version 1

This project started as a class assignment - build something using the C++ fundimentials learned over the semester. I descided to build a lidar, and started designing right away. I only had two weeks before I had to showcase the project, so only certain features were included. To add to the prussre, this was my first time using Onshape, so I was concurently learning Onshape and programming when parts were 3D printing. I finished the project a few days early, and polished the code and design just a little before producing the showcase video. I aced the assignment, but the lidar left quite a bit to be desired. For this to be a functional tool, I needed to improve the design and ease of use.
